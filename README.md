# Java Encapsulation Example

This project demonstrates Encapsulation in Java using a real-time bank example.

## Concept Used
- Private variables
- Public getter and setter
- Validation inside setter
- Data hiding

## Example

Class:
- HdfcBank with private balance
- getBalance() and setBalance() methods

Test:
- BankTest with main method

## Output

If balance >= 100 → value is set  
If balance < 100 → error message shown

## Run

Open BankTest.java and run main method.
